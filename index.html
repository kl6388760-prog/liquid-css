Installation

Установка

Link the stylesheet, load the typeface, and place your UI on a pure black canvas. That's the material's natural environment.

Подключите stylesheet, загрузите шрифт и разместите интерфейс на чистом чёрном фоне. Это естественная среда материала.

<!-- 1. Elegant typeface (one family) -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter+Tight:wght@400;500;600&display=swap" rel="stylesheet">

<!-- 2. Liquid CSS -->
<link rel="stylesheet" href="main.css">

<!-- 3. Pure black canvas -->
<style>
  body {
    background: #000;
    color: var(--text-primary);
    font-family: var(--font-sans);
  }
</style>

Specular highlight

Спекулярный блик

The only radial gradient in the library. Add .lg-specular to any glass element and update --lg-x / --lg-y on mousemove to make the highlight follow the cursor.

Единственный радиальный градиент в библиотеке. Добавьте .lg-specular к любому стеклянному элементу и обновляйте --lg-x / --lg-y на mousemove, чтобы блик следовал за курсором.

<button class="lg-btn lg-btn--md lg-specular">Continue</button>

<script>
  document.querySelectorAll('.lg-specular').forEach(el => {
    el.addEventListener('mousemove', e => {
      const r = el.getBoundingClientRect();
      el.style.setProperty('--lg-x', ((e.clientX - r.left) / r.width) * 100 + '%');
      el.style.setProperty('--lg-y', ((e.clientY - r.top) / r.height) * 100 + '%');
    });
    el.addEventListener('mouseleave', () => {
      el.style.setProperty('--lg-x', '50%');
      el.style.setProperty('--lg-y', '50%');
    });
  });
</script>

Accessibility

Доступность

  • Focus-visible — buttons and inputs show a 1px white outline at 3px offset. Never removed.
  • Reduced motion — under prefers-reduced-motion: reduce, transforms and the cursor specular are disabled; transitions collapse to ~0ms.
  • Native semantics — use <button type="button">, <label> for inputs, and <input type="checkbox"> behind the toggle.
  • Contrast — body text uses rgba(255,255,255,0.6) on pure black (≈ 8.5:1), headings 0.92. Keep disabled states out of critical flows.
  • Modals — role="dialog", aria-modal="true", focus trap via JS (optional) and Esc to close.
  • Focus-visible — кнопки и поля показывают белый контур 1px со смещением 3px. Он никогда не убирается.
  • Reduced motion — при prefers-reduced-motion: reduce трансформации и курсорный спекуляр отключаются; переходы сжимаются до ~0мс.
  • Нативная семантика — используйте <button type="button">, <label> для полей и <input type="checkbox"> под переключателем.
  • Контраст — основной текст rgba(255,255,255,0.6) на чистом чёрном (≈ 8.5:1), заголовки 0.92. Не выводите отключённые состояния в критичных сценариях.
  • Модалки — role="dialog", aria-modal="true", опциональный фокус-трап на JS и закрытие по Esc.

Browser support

Поддержка браузеров

  • Modern Chrome, Edge, Safari, Firefox — backdrop-filter ships everywhere.
  • For older Safari use the -webkit-backdrop-filter fallback (already included).
  • If backdrop-filter is unsupported, the translucent fill and inner shadows still read as glass — the material degrades gracefully.
  • Современные Chrome, Edge, Safari, Firefox — backdrop-filter поддерживается везде.
  • Для старых Safari используется fallback -webkit-backdrop-filter (уже включён).
  • Если backdrop-filter не поддерживается, полупрозрачная заливка и внутренние тени всё равно читаются как стекло — материал деградирует изящно.
